ما هي هذه المهارة؟

مهارةٌ تُعلِّمُ وكلاءَ الذكاء الاصطناعي أن يصححوا النص العربي ويعربوه ويشرحوا قواعده، لا أن يكتفوا بقول «هذا خطأ». تجمع بين جامع الدروس العربية لمصطفى الغلاييني، والنحو الوافي لعباس حسن، وتضبط كل تعديل بسبب.

أربع قواعد: المعنى أولاً، أقل تعديل، كل تعديل بسببه، لا حكم بلا كتاب.

لماذا هذه المهارة؟

لأن الخطأ النحوي لا يُصحح بالحدس، ولا تُبنى الثقة على «هذا هو الصواب» بلا سبب. المهارة تجعل التشخيص خطوة مستقلة، والسبب جزءاً من التصحيح، والخلاف معلناً لا مخفياً.

For English readers

An open agent skill for Arabic grammar correction and إعراب. It diagnoses the sentence, classifies the error, applies the smallest correct edit, explains the rule from classical and modern grammar books, and produces a clear parsing table. It covers the nominal and verbal sentence, case markers, the fourteen منصوبات, morphology, hamza orthography, punctuation and common modern errors. Works with Claude Code, Codex, Antigravity and VS Code agent harnesses.

المراجع

«جامع الدروس العربية» لمصطفى الغلاييني (ثلاثة أجزاء)، و«النحو الوافي» لعباس حسن (أربعة أجزاء). إقرار بالفضل: هذه المهارة صياغة تعليمية مستقلة لمبادئ الكتابين، مع نقل قواعد وأمثلة بإسنادها إلى أبوابها؛ ولا يتضمّن المستودع نسخاً كاملة من الكتابين.

النحو والإعراب — مهارة مستخلَصة من جامع الدروس العربية والنحو الوافي، ومسنَدة بمهارة الكتابة العربية.
